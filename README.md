# User Directory (React)

A simple React application that fetches and displays user data from a public API, with real-time search functionality.

## 🔧 Technologies Used
- React (Functional Components & Hooks)
- JavaScript (ES6)
- Fetch API
- Git & GitHub

## ✨ Features
- Fetches user data from an external API
- Displays users in a clean list format
- Real-time search/filter by user name
- Loading state handling

## 🧠 What I Practiced
- Using `useState` and `useEffect`
- Managing component state
- Conditional rendering
- Client-side filtering
- Clean component structure

```bash
git clone <your-repo-link>
